# Zon Landing Page (v2.5)

A premium, highly animated landing page for the **Zon** app. Features extensive GSAP animations, glassmorphism, skeuomorphism, and a bold Electric Orange accent color.


## Tech Stack
- **React 18**
- **GSAP 3.12** (Core, ScrollTrigger)
- **Tailwind CSS** (Styling & Layout)
- **Lucide React** (Icons)

## Usage

```tsx
import { ZonLandingPage } from '@/sd-components/e9af5ec7-674a-48db-bdcf-d88558dd33bb';

function App() {
  return <ZonLandingPage />;
}
```

## Props
This component currently accepts no props as it is a full page implementation.
